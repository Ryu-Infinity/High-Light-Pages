1. 事業者情報

本アプリ「High Light!」(以下「本アプリ」) は、個人開発者 (以下「運営者」) が提供する iOS アプリケーションです。

2. 収集する情報

本アプリは以下の情報を収集・処理します。

【アカウント情報】

Firebase Authentication により、メールアドレス・パスワードによる認証を行います。ユーザー ID (UID)・メールアドレス・表示名を保存します。

【ライブ記録・セットリスト】

ユーザーが入力したライブ記録 (アーティスト名・会場・日時・セットリスト・メモ等) をデバイス内 (SwiftData) に保存します。「公開セトリ」として公開設定したデータは Firebase Firestore に保存され、他のユーザーが閲覧できます。

【写真データ】

ライブ写真はデバイス内に保存されます。クラウドへのアップロード機能を追加する際は事前にご説明します。

【位置情報】

会場選択時に位置情報 (緯度・経度) を取得・保存します。位置情報はアプリの外部に送信されません。

【Apple Music / MusicKit】

楽曲検索のために Apple Music ライブラリへのアクセス許可を求める場合があります。音楽ライブラリのデータは本アプリ内でのみ使用し、外部サーバーへ送信しません。

【Apple ヘルスケア (HealthKit)】

過去のライブ参戦日に対応するアクティビティ (歩数・消費カロリー・移動距離・心拍・上った階数) を Apple ヘルスケアから読み取り、ライブ詳細に表示します。データはお使いの端末内のみで利用され、外部サーバーへは一切送信されません。

【プロフィール情報】

ユーザー名・自己紹介文・プロフィール画像 (サムネイル) は Firestore に保存され、フォロワー等が閲覧できます。

【トークメッセージ】

相互フォロー済みユーザー間のメッセージは Firestore に保存されます。

3. 情報の利用目的

収集した情報は以下の目的で利用します。

  • ライブ記録・セットリスト管理・通知などの基本機能の提供
  • アカウントの識別と認証
  • 公開セットリストの共有機能
  • フォロー・トーク機能の提供
  • アプリの改善および不具合対応
  • 不正利用・スパム行為の防止

4. 情報の第三者提供

以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

【利用するサービス】
  • Firebase / Google Cloud Platform (認証・データベース・ストレージ)
  • Apple Inc. (App Store、MusicKit、HealthKit)
【法令遵守】

法令に基づく開示要請があった場合。

※ 公開設定されたセットリストは、本アプリの全ユーザーが閲覧できます。

5. データの保持と削除

  • アカウント削除により、Firestore 上のプロフィール・公開セットリスト・メッセージを削除します。
  • デバイス内データはアプリのアンインストールにより削除されます。
  • 削除のご要望は ryu.infinity.prod@gmail.com までご連絡ください。

6. セキュリティ

Firebase Security Rules によりデータへの不正アクセスを防止しています。ただし、インターネット上での完全な安全性を保証することはできません。

7. 年齢制限

本アプリは 13 歳未満の方の利用を想定していません。13 歳未満の方の登録が判明した場合、アカウントを削除します。

8. 自動更新サブスクリプションについて

本アプリは「High Light! Pro」などの自動更新サブスクリプション (Auto-Renewable Subscription) を提供する場合があります。

  • 名称・期間・価格は App Store の商品ページに表示されます。
  • 支払いは購入確定時に Apple ID アカウントに請求されます。
  • サブスクリプションは現在期間の終了 24 時間前までに自動更新がオフにされない限り、自動的に更新されます。
  • 更新の管理および解約は、購入後に iPhone の「設定」→ Apple ID → サブスクリプション から行えます。
  • 無料試用期間が含まれる場合、未使用分は購入時に失効します。

9. 本ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更がある場合はアプリ内でお知らせします。変更後も継続してご利用いただくことで、変更内容に同意したものとみなします。
